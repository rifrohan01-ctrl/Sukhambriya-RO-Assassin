โปรดแตก ZIP และอัปโหลดไฟล์/โฟลเดอร์ทั้งหมดไปที่ root ของ GitHub repository (ไม่อัปโหลด ZIP ทั้งก้อน)

Render:
Language: Node
Build Command: npm install
Start Command: npm start
Root Directory: เว้นว่าง หาก package.json อยู่ที่ root
Environment Variables: เว้นว่างได้หากยังไม่ได้เชื่อม Supabase

ก่อน Deploy ตรวจว่ามี public/obb-items.json ใน GitHub จริง
หลัง Commit ใช้ Manual Deploy -> Deploy latest commit

หมายเหตุ: การติดตั้ง npm และการใช้งานจริงบน Render ยังต้องตรวจอีกครั้ง
