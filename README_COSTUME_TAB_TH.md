# Sukhambriya RO — แท็บแต่งตัวละคร

- ล็อกอินและสร้างชื่อตัวละครก่อน แล้วจึงเข้าเกมและเลือกแท็บ 🎭 แต่งตัวละครได้ภายหลัง
- บันทึก hair_style, hair_color, appearance.bodyPalette, appearance.cosmeticHat ใน Supabase public.characters ผ่านบัญชีที่ล็อกอินอยู่
- โหลดค่าจาก Supabase เมื่อเข้าเกมครั้งถัดไป
- ไม่แก้ตาราง player_game_state หรือกลไก OBB/ตีบวก
- ไม่มี SQL เพิ่มสำหรับชุดนี้ (ใช้ตาราง characters ที่เคยสร้างแล้วและ RLS ของเจ้าของบัญชี)
- ยังไม่เปลี่ยน Sprite ในสนามตามค่าที่เลือก เพราะไม่มีชุดภาพแอนิเมชันของทุกทรงผม/ชุด

## ติดตั้ง
แตก ZIP แล้วอัปโหลดไฟล์ภายในขึ้น GitHub โดยคงโครงสร้าง server.js, package.json, public ไว้ที่รากของ Repository จากนั้น Deploy latest commit บน Render

## ตรวจสอบ
1. Login และเปิดแท็บแต่งตัวละคร
2. เลือกค่าทรงผม สีผม สีชุด อุปกรณ์ -> กดบันทึก
3. ดูผลว่า 'บันทึกรูปลักษณ์ใน Supabase แล้ว'
4. Logout/Login -> ค่าเดิมต้องกลับมา
5. ทดสอบตีบวก OBB และคลังอาวุธเดิม

สำคัญ: ก่อนอัปโหลดทับเว็บจริง ให้สำรอง Commit ที่ใช้งานได้ล่าสุด เนื่องจาก ZIP นี้สร้างจากเวอร์ชัน Persistent Save ที่มีในบทสนทนา และอาจไม่รวมการแก้ไขใหม่บน GitHub หลังจากนั้น
