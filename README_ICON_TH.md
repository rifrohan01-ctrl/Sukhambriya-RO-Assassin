วิธีใช้งาน: อัปโหลดไฟล์ในโฟลเดอร์นี้แทนไฟล์เดิมทั้งหมดขึ้น GitHub แล้วให้ Render deploy ใหม่
โทรศัพท์ที่เคยติดตั้งแอปแล้ว อาจต้องลบไอคอนแอปเก่าและติดตั้งใหม่เพื่อแสดงรูปใหม่
Android: Chrome > จุดสามจุด > Install app หรือ Add to Home screen
iOS: Safari > Share > Add to Home Screen
ข้อควรระวัง: การเพิ่มลงหน้าจอมือถือไม่ได้ย้ายฐานข้อมูลออนไลน์ออกจาก Render และยังต้องมีอินเทอร์เน็ตสำหรับเกมออนไลน์
