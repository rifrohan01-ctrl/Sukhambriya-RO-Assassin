Sukhambriya RO — ปรับสมดุล Old Blue Box
===================================
ต้นเหตุเดิม: คำนวณเรทจากสัดส่วนจำนวนไอเทมในแต่ละหมวดของ Fire RO
ทำให้ Legendary 6.657% และ Epic 39.653% — สูงเกินไป

เรทใหม่เป็นเรทจำลองที่ออกแบบสำหรับ Sukhambriya RO เท่านั้น ไม่ใช่เรท Fire RO ทางการ:
Legendary 0.1%
Epic 1.0%
Rare 5.0%
Uncommon 68.9%
Common 25.0%

สุ่มกลุ่มก่อน แล้วจึงสุ่มไอเทมภายในกลุ่ม โดยยังมีรายการ 691 ชิ้นเท่าเดิม
การเปิด 100 กล่อง คาดหวัง Legendary เฉลี่ย 0.1 ชิ้น, Epic เฉลี่ย 1 ชิ้น
รายการแยกหมวดมาจาก Fire RO ซึ่งไม่ใช่ราคาตลาด/ความหายากแท้ของทุกไอเทม
เช่น Novice Shield และ Spicy Sauce อยู่ในหมวดหายากพิเศษตามรายการต้นทาง
ควรจัดอันดับรายชิ้นใหม่ภายหลังถ้าต้องการให้ของแพงจริงอยู่ระดับสูง

โหมดออฟไลน์: หากเคยเปิดกล่องมาก่อน localStorage ของเว็บเบราว์เซอร์ยังคงจำนวนกล่อง/Inventory เดิม
การเปลี่ยนเรทมีผลเฉพาะการสุ่มครั้งใหม่ ไม่มีการลบของเก่า
โหมดออนไลน์: อัปโหลดทั้งไฟล์ server.js, obb-data.js, public/obb-items.json,
public/obb-catalog.js และไฟล์เกมอื่นใน ZIP แล้ว Deploy ใหม่บน Render
ก่อนเปิดให้เล่นจริง ควรตรวจจำนวนกล่องรวมที่ได้จากการขายคืน เพราะราคาขาย Epic/Legendary
อาจสูงเกินไปสำหรับเรทใหม่
