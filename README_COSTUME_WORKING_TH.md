# ระบบแต่งตัว Sukhambriya RO

มีอุปกรณ์แฟชั่นวาดใหม่ 12 รายการ 4 สล็อต: upper/middle/lower/garment ทดลองสวมและถอดได้จริงบนพรีวิว Assassin และบนตัวละครในสนาม Monster Hunt; บันทึกลง characters.appearance.costumeSlots ด้วย Supabase, โหลดกลับตอน Login

อุปกรณ์เป็นภาพต้นฉบับสร้างใหม่ในโค้ด (SVG) ไม่ได้คัดลอก Sprite หรือภาพอุปกรณ์จากเว็บไซต์ iRO Wiki ที่สิทธิ์การนำไปเผยแพร่ยังไม่ชัดเจน ภาพผ้าคลุมเป็นเลเยอร์ 2D ที่ไม่หมุนตามทุกทิศและอาจไม่พอดีช่วงโจมตี ซึ่งเป็นข้อจำกัดเวอร์ชันทดลอง

ติดตั้ง: อัปโหลดไฟล์ทั้งโฟลเดอร์ไป GitHub โดยคง server.js package.json public ไว้ระดับบนสุด แล้ว Deploy latest commit บน Render ไม่ต้องรัน SQL เพิ่ม ใช้ characters.appearance เดิม

ทดสอบ: Login > แต่งตัวละคร > เลือกหมวก/แว่น/หน้ากาก/ผ้าคลุม > ตรวจตัวละครเปลี่ยน > บันทึก > Logout/Login > ตรวจชุดเดิม > เข้า Monster Hunt ตรวจการแสดงผลบนตัวละคร
