# Fire RO Old Blue Box — ชุดฐานข้อมูลนำเข้าจากไฟล์ HTML ของผู้ใช้

- ตรวจพบข้อมูลและ Item ID ครบ 691 รายการ: 46 / 274 / 37 / 332 / 2 ตามลำดับหายากพิเศษ / หายากมาก / หายาก / ทั่วไป / เจอบ่อย
- แทนที่รายการเดิม 73 รายการแล้ว ไม่ใช้รายการเก่าเมื่อสุ่ม
- เริ่มต้นกล่อง 1,000 ใบ (สำหรับข้อมูลผู้เล่นใหม่เท่านั้น)
- รายการและรหัสภาพดึงจาก HTML ที่ผู้ใช้อัปโหลด ไม่ต้องดึงเว็บขณะเปิดเซิร์ฟเวอร์
- แสดงภาพด้วยลิงก์ https://www.fire-ro.com/img/items/<ItemID>.png จึงต้องมีอินเทอร์เน็ต และเว็บไซต์ต้นทางต้องเปิดให้ดึงภาพ
- **ไฟล์ภาพ PNG ไม่ได้ถูกบรรจุใน ZIP** เนื่องจากไฟล์ HTML ที่ผู้ใช้ส่งมาไม่มีไฟล์ PNG และยังไม่ได้ยืนยันสิทธิ์ทำสำเนาหรือแจกจ่ายภาพต่อ
- รูปอาจไม่ขึ้นหาก Fire RO จำกัดการ hotlink หรือเปลี่ยนเส้นทาง
- หน้า Fire RO แสดงกลุ่มความหายาก แต่ไม่แสดงอัตราสุ่มจริง ชุดนี้กำหนดไอเทม 691 ชิ้นให้มีโอกาสเท่ากันชิ้นละ 1/691 (~0.144718%) กลุ่มจึงมีเรทตามจำนวนรายการ 46/691, 274/691, 37/691, 332/691, 2/691 โดยไม่อ้างว่าเป็นเรททางการ
- กลุ่มในเกมจับคู่ หายากพิเศษ=Legendary; หายากมาก=Epic; หายาก=Rare; ทั่วไป=Uncommon; เจอบ่อย=Common
- ชุดนี้คงโหมดตีบวก/คลัง/เปิด OBB/ขายของ/ล่ามอน (กดเอง) ไว้

เปิด offline: public/index.html (ชื่อ/รายการแสดงได้ แต่รูปไอเทมต้องมีอินเทอร์เน็ต)
เปิด online: npm install และ npm start
หมายเหตุ: ข้อมูลผู้เล่นออนไลน์ยังเป็นเซสชัน ไม่ได้จัดเก็บถาวร
