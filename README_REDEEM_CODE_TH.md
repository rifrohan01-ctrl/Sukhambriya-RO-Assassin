รหัสเติมกล่อง OBB
===================
9999obb = เพิ่ม Old Blue Box 9,999 กล่อง
ใช้ได้ 1 ครั้งต่อข้อมูลในเบราว์เซอร์ (ออฟไลน์) หรือ 1 ครั้งต่อเซสชันออนไลน์
เกมปัจจุบันยังไม่มีระบบบัญชีผู้เล่นและฐานข้อมูลผู้ใช้ถาวร จึงไม่สามารถบังคับใช้โค้ดครั้งเดียวต่อบัญชีตลอดไปได้ และเมื่อเชื่อมต่อใหม่อาจใช้ซ้ำได้
ออนไลน์: เซิร์ฟเวอร์ตรวจรหัสและเพิ่มกล่องเอง ไม่ยอมรับจำนวนกล่องจาก client
ออฟไลน์: บันทึก localStorage ผู้เล่นสามารถลบ localStorage เองได้
